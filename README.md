# FinVision — 決算ビジュアルアナライザー

決算書（貸借対照表・損益計算書）の数値を読み込み、財務構造を図解し、
安全性・収益性・効率性を自動診断するシングルページアプリです。
`index.html` 1ファイルのみで動作し、サーバーは不要です。

**すべての処理はブラウザ内で完結します。決算書ファイルがどこかに送信されることはありません。**

---

## 決算書PDFの読み込み

画面上部の読込ゾーンにPDFをドラッグ＆ドロップするか、「PDFファイルを選択」から指定します。

### 対応するPDFの種類

| 種類 | 判定 | 処理 |
| --- | --- | --- |
| 文字情報を持つPDF（会計ソフトから直接出力したもの） | 自動 | 文字レイヤーから抽出（数秒） |
| スキャン画像のPDF（複合機で紙をスキャンしたもの） | 自動 | OCRで読み取り（1ページ数秒〜） |

スキャンPDFかどうかは先頭3ページの文字数で自動判定します。文字情報が無い場合のみ
OCRエンジン（Tesseract.js 日本語）をその場で読み込むため、通常のPDFでは
OCRの待ち時間もダウンロードも発生しません。

> OCRは初回のみ日本語辞書の取得に十数秒かかります。2回目以降はブラウザキャッシュから読み込まれます。

### 読み取れる計算書類

会計事務所・税務ソフトが出力する「決算報告書」様式を対象としています。

- **貸借対照表** — 現預金計 / 当座資産計 / 棚卸資産計 / その他流動資産計 / 流動資産計 /
  有形固定資産計 / 投資その他の資産計 / 固定資産計 / 資産の部合計 /
  流動負債計 / 固定負債計 / 負債の部合計 / 純資産の部計
- **損益計算書** — 純売上高 / 売上原価 / 売上総利益 / 販売費・一般管理費計 / 営業利益 /
  営業外収益・費用 / 経常利益 / 税引前当期純利益 / 法人税・住民税・事業税 / 当期純利益
- **販売費及び一般管理費** — 科目別の内訳をすべて抽出し、上位10科目のグラフと
  人件費率（役員報酬・給与手当・賞与・法定福利費などの合算）を表示します
- **会社名・会計期間** — 「第4期」「自 令和7年6月1日 至 令和8年5月31日」等を和暦から西暦へ変換

金額の単位（円 / 千円 / 百万円）は「（単位：円）」などの記載から自動判定し、
内部単位である百万円へ換算します。判定できなかった場合は確認画面で選択を求めます。

### 読み取り後は必ず確認画面が出ます

抽出した金額は**そのまま反映されません**。確認画面で以下を提示し、承認して初めて反映されます。

- 科目ごとの金額と、その根拠となったPDFの行（ページ番号付き）
- 出所バッジ — `PDF`（決算書に記載）/ `算出`（他の科目から計算）/ `未検出`
- 貸借一致チェック（資産合計と負債・純資産合計の差額をリアルタイム表示）
- 「当期」「前期」どちらとして反映するかの選択（2期比較はPDFを2回読み込みます）

値はその場で修正できます。OCRは桁の読み違いが起こり得るため、**反映前に決算書と
見比べて確認してください。**

## その他の入力方法

- **テキスト読込** — PDFからコピーしたテキストを貼り付けて解析（PDFと同じ確認画面を通ります）
- **数値調整** — 全項目の手入力。入力単位（円 / 千円 / 百万円）を選べます
- **サンプルデータ** — IT/SaaS・訪問看護・リユース買取の3モデル

## 主な機能

- B/S構造図・P/L構造図（ブロック図 / ウォーターフォール図）、2期比較表示
- 安全性（流動比率・当座比率・自己資本比率・固定比率）
- 収益性（営業利益率・ROA・ROE・売上高当期純利益率）
- 効率性（総資産回転率・棚卸資産回転期間・財務レバレッジ・デュポン分解）
- 業界平均とのレーダーチャート比較（医療・介護・福祉系5モデルを含む9業種）
- 資金繰り診断（現預金月商比・在庫拘束資金）
- 感度シミュレーション、目標利益からの逆算（ゴールシーク）
- 財務分析レポートのPDF出力

## 動作要件

モダンブラウザ（Chrome / Edge / Safari / Firefox）。
Tailwind CSS・Chart.js・PDF.js・Tesseract.js をCDNから読み込みます。
社内ネットワーク等でCDNがブロックされている場合、グラフとPDF読込は無効になりますが、
数値の入力・分析・表の表示は引き続き利用できます（起動時に画面上部で通知します）。

## 開発

ビルド不要です。`index.html` を編集してブラウザで開くだけで確認できます。

```
npx http-server . -p 8080
```
