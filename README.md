# FinVision

決算書（B/S・P/L）の数値を読み込んで、財務構造・安全性・収益性・効率性を自動で図解する
単一HTMLファイルのビジュアルアナライザーです。`index.html` をブラウザで開くだけで動作します。

## 決算書の読み込み方法

| 入口 | 用途 |
| --- | --- |
| **決算書PDF読込** | 決算報告書PDFをそのまま投入する。テキスト埋め込みPDFでも、複合機でスキャンした画像PDFでも読み取れます |
| **テキスト読込** | PDFや会計ソフトからコピーした数値テキストを貼り付ける |
| **数値調整** | 12項目を直接手入力する（前期データの追加もここから可能） |

いずれの入口でも、解析結果は必ず **「読み取り結果の確認」画面** に表示されます。
金額を修正し、当期／前期のどちらに反映するかを選んでから確定する流れなので、
誤読された数値がそのままグラフに反映されることはありません。

## PDF読み取りの仕組み

1. **テキストレイヤーの抽出** — PDF.js のテキスト片をY座標でグルーピングして行に復元し、
   「科目名 + 金額」の表構造として解析します。
2. **スキャンPDFのOCR** — テキストが1文字も取れないPDF（複合機スキャン等）は画像と判断し、
   [Tesseract.js](https://tesseract.projectnaptha.com/)（日本語）をその場で読み込んでOCRします。
   ブラウザ内で完結するため、決算書が外部サーバーに送信されることはありません。
   - 各ページを約2400px幅で描画してOCR
   - 表題から帳票種別（貸借対照表／損益計算書／販売費及び一般管理費など）を判定
   - B/SとP/Lの主要科目が揃った時点で打ち切り（20ページの決算報告書なら通常4ページ程度で終了）
   - 縦向きに綴じられたページは自動で回転して再認識
   - 初回のみ日本語学習データ（数十MB）をCDNから取得します。取得先を変更したい場合は
     `localStorage.setItem('finvision.ocrSource', JSON.stringify({js, worker, core, lang}))`
3. **勘定科目のマッチング** — 「現 預 金 計」のような字間の開いた科目名に対応するため、
   空白・記号を除去したキーで辞書と突き合わせます。OCRの誤字（`経常利座`→`経常利益` など）は
   編集距離による曖昧一致で救済します。
4. **単位の判定と換算** — `（単位：円）`『千円』『百万円』を検出してアプリ内部の百万円に換算します。
   単位表記が無い場合は金額の桁と端数から推定し、確認画面で選び直せます。
5. **検算** — 貸借一致（資産合計 = 負債 + 純資産）、資産・負債の内訳合計、
   営業利益・当期純利益の積み上げを照合し、合わない場合は確認画面に警告を表示します。

## 主な画面

- **B/S構成図・P/Lブロック図／ウォーターフォール図** — 構成比を面積で可視化
- **安全性・収益性・効率性の自動診断** — 流動比率、自己資本比率、営業利益率、ROA、ROE、
  総資産回転率、デュポン分解などを判定コメント付きで表示
- **業界平均レーダー比較** — 医療・介護・リユース等の業種モデルとスコア比較
- **資金繰り診断／ゴールシーク／利益シミュレーション**
- **A4財務レポートPDF出力**

## 制約

- アプリ内部の表示単位は百万円固定です。円建ての小規模決算書では表示が丸められます
  （読み取った元の金額は確認画面の「抽出された勘定科目の一覧」で確認できます）。
- CDN（Tailwind CSS / Chart.js / PDF.js / Tesseract.js）を利用するため、初回表示と
  スキャンPDFのOCRにはインターネット接続が必要です。
